# JavaScript Examples

This folder contains standalone JavaScript examples inspired by the TaskMail project.

## Intent Router

`intentRouter.js` demonstrates a simple rule-based approach to identifying user requests without calling an AI model.

It includes input validation, Greek text normalization, keyword matching, and fallback handling.

### Run locally

Requires Node.js.

```bash
node examples/intentRouter.js
```

Run the command from the repository root.

This is a simplified educational example, not the complete TaskMail application.
